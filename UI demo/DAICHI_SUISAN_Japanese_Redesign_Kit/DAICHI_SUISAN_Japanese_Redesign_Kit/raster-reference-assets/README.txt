DAICHI SUISAN — Japanese-inspired website asset pack

Contents
- 00_full_asset_sheet.png: full visual reference sheet.
- 01–12: grouped transparent PNG crops of frames, patterns, Japanese ornaments, backgrounds, icons, buttons, cards, navigation and overlays.

Important
- These are raster PNG reference assets generated from the visual concept, not original editable SVG/HTML components.
- Some crops intentionally contain multiple items and/or small labels from the sheet. For production UI, recreate text, buttons, cards and navigation in HTML/CSS so they remain responsive and accessible.
- Best uses: decorative corner overlays, section backgrounds, frame accents and visual direction.
- Suggested palette: deep vermilion #9F171B, dark navy #102E46, pine green #075B3B, warm ivory #F7EEDB, antique gold #C99A45.
- Use background-size: cover for section backgrounds and contain for isolated ornaments. Keep text and interactive controls as live HTML.
