# DAICHI SUISAN — Japanese UI Vector Kit

Bộ tài nguyên giao diện phong cách Nhật Bản cổ điển, dùng SVG vector độc lập và CSS component thuần.

## Nội dung
- `assets/`: SVG có thể phóng to không vỡ: khung đỏ-vàng, khung giấy, họa tiết sóng Seigaiha, mây Nhật, mặt trời/núi Phú Sĩ, hoa anh đào, cổng Torii, quạt Nhật.
- `css/daichi-ui.css`: biến màu và component CSS: section, frame, card, button, badge, nav, input, divider, responsive.
- `components/demo.html`: trang demo HTML tự chứa để xem cách sử dụng.

## Dùng nhanh
1. Giải nén thư mục vào dự án.
2. Sao chép `assets/` và `css/` vào thư mục public của website hoặc điều chỉnh đường dẫn.
3. Thêm `<link rel="stylesheet" href="/assets/daichi-ui.css">` với đường dẫn thực tế đã cấu hình.
4. Dùng class `ds-section`, `ds-frame`, `ds-card`, `ds-btn ds-btn--red`, `ds-btn ds-btn--green`, `ds-badge`.

## Lưu ý
- Đây là starter kit vector/CSS, không phải bản sao pixel-perfect của ảnh mockup.
- Ảnh sản phẩm trong demo là minh họa; hãy thay bằng ảnh sản phẩm thật.
- Font Be Vietnam Pro và Noto Serif được tải từ Google Fonts; có thể đổi sang font local nếu cần.
