# DAICHI SUISAN — Bộ tài nguyên thiết kế lại website

Gói này gồm các tài nguyên vector/CSS, bảng tham khảo PNG và hai ảnh mockup giao diện được tạo trước đó.

## Cấu trúc
- `vector-ui-kit/`: SVG vector độc lập, CSS design system và HTML demo.
- `raster-reference-assets/`: bộ bảng PNG tổng hợp tài nguyên để tham khảo khi chọn họa tiết.
- `design-references/`: hai ảnh mockup trang web và hai bảng tổng quan asset.
- `CODEX_PROMPT_VI.md`: prompt tiếng Việt để giao Codex chỉnh sửa giao diện trong repository hiện tại.

## Cách dùng với Codex
1. Giải nén ZIP này.
2. Mở Codex tại thư mục repository của website thật (không phải chỉ mở thư mục tài nguyên này).
3. Đưa thư mục `DAICHI_SUISAN_Japanese_Redesign_Kit` vào workspace của Codex hoặc sao chép thư mục này vào repository.
4. Mở `CODEX_PROMPT_VI.md`, sao chép toàn bộ nội dung và gửi cho Codex.
5. Cho Codex kiểm tra thay đổi, chạy dự án và xem preview trước khi chấp nhận.

## Lưu ý
Các ảnh mockup chỉ dùng làm tham chiếu thị giác. Hãy yêu cầu Codex dùng HTML/CSS/SVG và dữ liệu/component thực tế của website, không đặt ảnh mockup toàn trang làm nền.
